# Architectural Styles

| Style | When | Risks |
|---|---|---|
| Monolith | Small teams | God modules |
| Modular monolith | Growing teams | Boundaries erode |
| Microservices | Many teams | Distributed complexity |
| Serverless | Spiky traffic | Cold starts |
| Hexagonal | Domain-rich | Boilerplate |
| Event-driven | Async | Eventual consistency |
